# Number Guessing Game

A Python-based interactive game that generates a random number between 1 and 100 and challenges the user to guess it. The program provides hints, validates input, tracks attempts, and allows the player to play multiple rounds.

## Features
- Random number generation
- Input validation
- Too high / Too low hints
- Attempt counter
- Performance feedback
- Play again option

## Technologies Used
- Python 3
